# 26.11.14「当前」标记

## 需求
设置-存储里标出当前正在运行的那一个安装包、服务器页里标出当前选中的那一台，
这两处原来的浅灰胶囊在浅色主题下几乎与背景分不开。改成实心反转色药丸：
浅色主题近黑底白字、深色主题近白底深字，切换主题时颜色跟着翻。

## 改动
| 文件 | 位置 | 改动 |
| --- | --- | --- |
| `qbpanel/app/web/index.html` | 服务器卡「当前」 | `class="chip"` → `class="tagcur"` |
| `qbpanel/app/web/index.html` | 存储表「当前版本」 | `class="chip"` → `class="tagcur"`，`margin-left` 保留 |
| `qbpanel/app/web/style.css` | `.chip` / `.dot` 之后 | 新增 `.tagcur` |
| `qbpanel/app/web/index.html` | `<link>` 的 `?v=` | 26.11.10 → 26.11.14 |
| `qbpanel/manifest` | `version` | 26.11.13 → 26.11.14 |

`.tagcur` 用 11px 字 / 3px 6px 内边距 / 5px 圆角，取 `--primary` + `--primary-fg`。
这两枚 token 在浅色主题是 #1c1c1c / #fafafa、深色主题是 #e5e5e5 / #1c1c1c，
所以主题切换不需要任何额外逻辑，属性一变颜色就地翻转。

没有动：`.chip` 基础类与 `.chip.ok / .chip.err` 变体、服务器在线状态胶囊（那是状态色，
不是选中标记）、i18n 文案与后端。

## 验证
- 探针页读真实 `index.html` + 真实 `style.css`（只注入 `<base>` 让相对路径指回产品目录），
  无头 Chrome 渲染后量像素：服务器卡药丸 34×17、存储表药丸 56×17（四个字），高度与目标一致。
- 运行时把 `data-theme` 从 light 切成 dark 再切回，读 `getComputedStyle`：
  浅 (28,28,28)/(250,250,250) → 深 (229,229,229)/(28,28,28) → 浅，font-size 11px、圆角 5px 不变。
- 四个「视图 × 主题」组合的 console.error 与未捕获异常全为空；手机 390px 下不换行、不溢出。
- `tools/check_icon_case.py` 通过。
